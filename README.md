# 우주의 숲

반 친구 30명이 석기 · 철기 · 산업 시대 섬을 거쳐 우주 연구소 섬까지 가는 우주 탐사의 역사 마을 (과학 2, Ⅷ. 별과 우주 - 우주 탐사).

- 게임: https://moonclipse-t.github.io/Space-Forest/
- 선생님 화면: https://moonclipse-t.github.io/Space-Forest/?teacher=1

우주 시대 이전 섬은 재미 퀴즈와 그림 시험, 우주 시대는 교과서 퀴즈와 탐사 계획서입니다. 선생님 OK를 받으면 언덕 위 시간의 포탈이 열립니다. 학생 기기에서 바로 OK할 때는 선생님 암호가 필요합니다.

반 전체가 함께 하려면 선생님 화면(?teacher=1)에서 방 번호를 열고, 학생들은 첫 화면에 그 방 번호를 씁니다. 방 번호를 비우면 봇 친구 29명과 혼자 합니다.
